VISITOR COUNTER
A simple, privacy-friendly visit counter (no personal data collected) is in the footer,
powered by a free service (hits.sh). It only counts page loads — nothing about the visitor
is stored. Automatically capturing a visitor's real name/phone number is not something a
website can do unless they type it in themselves (which already happens through your
Contact form/WhatsApp button).

BEFORE PUBLISHING
1. Replace all placeholder images listed above with real photos (keep the exact filenames).
2. Confirm your current CIDB grade/details (shown in the About section stats).
3. Add a company email address in the Contact section if you have one.
4. Update the Company Experience table if new projects are completed.
5. Upload every file in this folder (flat, no subfolders) to your GitHub repo — Vercel will redeploy automatically.
