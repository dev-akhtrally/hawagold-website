Hawa Gold Construction & Services Website
==========================================

This is a ready-to-upload responsive website for hawagold.com.my.

Files:
- index.html — main website
- styles.css — design and responsive layout
- script.js — mobile menu and WhatsApp enquiry form
- assets/hawa-gold-logo.jpg — full logo (icon + wordmark), used in the hero section
- assets/hawa-gold-icon.jpg — cropped circular icon-only version, used in the header/nav and About section
- assets/favicon-64.jpg — small icon used as the browser tab favicon

Before publishing:
1. Confirm your current CIDB grade/details (shown in the About section stats).
2. Replace the 3 project placeholders with real project photos.
3. Add a company email address in the Contact section if you have one.
4. Point the domain hawagold.com.my to your hosting (see the deployment notes Claude gave you).
5. Upload all files, keeping the assets/ folder structure, to your hosting's public_html folder.
